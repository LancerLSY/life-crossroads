# 人生岔路 · Otherlife

一个从随机出生开始的像素风人生模拟游戏。选择过去、当下或未来的世界，在连续流动的时间里学习、工作、经营关系，经历一段没有固定轨迹的人生。

玩法参考 [80亿分之1](https://1in8b.life/zh-hans/)，程序、叙事、名称和美术为独立实现。基础功能对照见 [功能核对表](docs/parity.md)，本次实际使用官方 **REA 6.7.0** 分析发布程序的像素与时钟流程，证据见 [REA 重建说明](docs/rea-reconstruction.md)。

## 开始运行

需要 Node.js **22.18 或更新版本**。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。前端与 API 服务会一起启动，API 在 3001 端口。没有模型密钥时，完整本地模拟仍可游玩。

## 接通 DeepSeek

复制 `.env.example` 为 `.env.local`，在本地填写：

```dotenv
DEEPSEEK_API_KEY=你的真实密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

重启服务，在游戏设置中刷新连接状态。模型名可按账户可用模型修改。接口使用 DeepSeek Chat Completions 的 JSON 输出；模型只负责事件叙事和人物对话，年龄、资产、教育和关键决定仍由模拟规则控制。

密钥仅在服务端读取。**不要使用 `VITE_` 前缀，不要提交真实 `.env` 文件。** 可配置 `GAME_ACCESS_TOKEN` 限制共享站点的模型访问；访问口令只在当前浏览器页面会话中使用。

“世界智能”调节叙事丰富程度、NPC 主动发言和事件发散程度。0 为本地模式；快转时优先在抉择处请求模型，80 以上也生成途中故事。对话保留人物性格、关系、共同记忆和近期世界事件。请求失败时会显示提示并使用本地故事。

## 玩法

- 原生 **192×60** 动态像素生活场景与 **24×32** 人物肖像；年龄、家庭成员、居住环境、房屋、职业及明暗主题会改变画面。点击场景中的家人即可开始对话。

- 在 172 个国家与地区中，按出生人数或总人口权重抽取出生地；也可展开自定信息，指定出生地和名字。每一生从 0 岁开始，有独立随机种子、性别、家庭条件和父母。
- 过去的世界随历史数据演变；当下冻结基准条件；未来使用明确标注的游戏情景。自由选择出生年份是本作额外功能。
- 30 / 60 / 90 分钟控制一生的播放节奏；支持暂停、1 / 2 / 4 / 8 / 12 / 16 倍速、快转至下个抉择和自动抉择。重要选择与阶段手记会阻止时间继续。
- 做选择发生在当年，不会直接增加年龄。年度重心从 6 岁起开放，按当年投入时间加权结算。
- 教育、工作、晋升、退休、伴侣、育儿、医疗和迁居影响后续机会与收支。家庭账本支持消费、房产、贷款和七种投资政策，投资可能亏损。
- 四位同年出生的人使用相同模拟规则独立经历一生。人生格子记录每年状态，存活曲线展示模拟模型的群体风险。
- NPC 有信任、亲密、性格、心情、对话和记忆；成年后的伴侣关系需要明确选择。已离世人物的记忆保留，不能继续对话。
- 在 5 / 15 / 30 / 50 / 70 岁暂停写下感想。可以收藏纪录、下载出生卡和结局卡，回看已完成的人生。
- 自动保存、JSON 导出/导入；最多保留 8 条人生或平行分支，每条保留最近 24 个回溯年份。回到选择前分岔，原来的未来仍然保留。

## 数据与模型边界

[数据说明](docs/data-sources.md) 记录了原始来源、单位、许可、缺失字段及插值方法。国家快照独立取自 World Bank WDI 和官方补充数据；当前 21 个地区的 23 个字段使用标注的代理值。早期缺失年份和未来条件为游戏情景。

寿命采用独立的概率风险模型，并非完整联合国逐岁生命表。统计环境影响机会，选择和随机性共同影响结果。它不是对个人寿命、收入或现实事件的预测。

已实现参考站的核心单人人生循环，未声称复刻其全部 148 类区域特殊决定。公共社区、跨用户追思馆、付费珍藏和原站的传输码服务不包含在本地版中；本地回看与 JSON 转移不依赖这些服务。

## 构建与验证

```sh
npm run check
npm run build
npm start
```

生产环境由同一个 Node 服务提供 `dist/` 和 `/api/*`，默认 http://127.0.0.1:3001 。容器或外部主机设置 `HOST=0.0.0.0`。HTTPS 反向代理须设置 `GAME_PUBLIC_ORIGIN=https://你的域名`。GitHub Pages 无法运行此 Node 后端。

当前96项测试通过。验证包含像素画布确定性、家庭筛选、年龄和房屋变化、明暗主题、结局画面，以及引擎完整生命周期、概率出生与死亡、资金记账、同年抉择、关系、跨分支存档、时钟中断及模拟 DeepSeek HTTP 测试。真实模型调用需要用户配置密钥，仓库不附带密钥。
