# REA 像素版重建计划

## 依据与目标

用户明确指定官方 REA（morluto/rea）并要求接近参考站的像素画风。当前在线原站连接失败，因此使用2026-10-22已保存的公开0.8.4发布文件，由REA做静态分析，并在隔离的本地预览中核对其实际画面。原版文件仅保留于临时研究目录，不进入本项目仓库。

## 实施顺序

1. 用官方REA6.7分析发布JavaScript，保存可核查的Evidence与覆盖边界。
2. 依据观察到的低分辨率画布、家庭/年龄/房屋/职业映射，独立编写像素场景和头像渲染器。
3. 将游戏页面调整为身份/状态、场景/年度重心/纪录、家庭/同龄人/地图三栏。
4. 删除上一版手绘图片引用，出生、人物、结局、分支都使用同一套像素视觉语言。
5. 验证不同年龄、家庭、城乡、房屋和明暗主题的画面差异；验证既有游戏和DeepSeek接口未发生回归。
6. 浏览器检查桌面及手机，提交并更新现有私有GitHub仓库。

## 验收

- 原生192×60像素场景，最近邻显示，没有模糊缩放或装饰性手绘背景。
- 房屋、人物年龄、家人数量、职业道具、地区环境和结局由真实游戏状态决定。
- 与参考站接近的冷灰绿纸色、酒红身份栏、青绿色强调、细边框小圆角面板；正文清楚可读。
- 既有连续时间、当年抉择、存档回溯、经济和NPC对话可用。
- REA证据明确标注真实工具输出与人工源码观察，不把静态推断冒充在线运行结果。
