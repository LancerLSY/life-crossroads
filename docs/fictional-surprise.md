# 缅甸虚构隐藏支线

本支线是用户指定的戏剧性游戏情节。**80%触发、触发后90%致死是虚构参数，不是现实缅甸旅行或犯罪风险的统计。** 它与出生家庭使用的调查概率分开计算。

成年角色完成从境外前往缅甸的旅行或迁居并成功支付后，抽取80%的入线结果。在当地出生或普通本地出行不触发。每年每种到访方式只抽取一次；刷新、重复点击及来回切换方式不能重抽已经记录的结果。

入线时同时固定结局：90%进入致死路线，10%进入脱险路线。玩家经历受困、传递消息、尝试脱险三段行动；每个选择立即生效，改变途中叙事，不改变已抽取的最终命运。致死路线在第三段结束时直接结束人生，死亡原因显示“嘎腰子”；叙述与像素画面不展示血腥细节。脱险可能留下持续伤势，并恢复此前未完成的抉择。

危机期间普通时间、消费、投资、迁居及外界对话暂停。保存包含阶段、动作、结局与待恢复事件，载入检查其一致性。剧情记录与玩家亲笔手记分别标注。

验证覆盖一万组种子的80%/90%概率、所有三段动作组合、重载结果一致、付款与成年资格、绕过拦截、旧存档兼容，以及伤势上限。浏览器已实际走完死亡和脱险路线并刷新确认。
