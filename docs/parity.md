## 本作新增

DeepSeek自由NPC对话、NPC之间的世界消息、可调世界智能、关系共同记忆、从旧年份分岔并在保留的未来间切换。

## 尚不等同的范围

- 使用独立数据及模拟模型，统计数值和每个随机结果不与原站逐项相等；目前没有原站全部地区、病种、历史冲突和148类特殊决定。
- 教育和家庭规则覆盖核心循环，未覆盖原站所有研究生、博士、宗教、民族、收养、监护、后代婚姻及地区特有系统。
- 跨用户社区、公共追思馆及点烛、付费珍藏、传输码/云同步需要另外的持久化服务，本地版未提供。
- 本地保留8条完整人生/分支；原站“最近10段人生”是不同的归档上限。

## 验证环境与限制

本地 Node25、Vite8、内置浏览器。已查看移动窄屏和1440×1000桌面布局；在内置浏览器确认出生卡、连续时间、16倍速快转及2岁抉择中断。浏览器审批服务曾暂时超时，重试恢复后，进一步确认收起抉择保持暂停、当年选择生效而年龄不变、NPC本地对话更新关系，以及从1984回溯到1982选择前并保留原未来。另确认刷新后2条分支分别停在1984与1982；新标签页控制台无错误，图片加载正常，桌面内容宽度等于视口宽度，无横向溢出。已检查390像素手机界面。截图只保留在浏览器工具输出中，未伪造本地截图文件。

DeepSeek HTTP 集成使用模拟响应验证；未提供真实密钥，尚未执行付费在线模型请求。
