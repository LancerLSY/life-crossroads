# 家庭出生概率：来源与可识别边界

数据文件：`src/simulation/family-data.json`。检索日期：2026-10-23。

此次实际下载 28,372 条官方记录，来自 340 份调查；通过完整出生次序分布校验后收录 337 份、87 个国家/地区、1985–2025 年。299 份调查具有完整五个财富组；37 份缺少财富组、1 份只有四组。旧调查缺项不得用数组位置冒充完整五分位。

## 实际取得的官方数据

DHS Program Indicator Data API 公开发布抽样调查的加权汇总。使用 `FE_BORD_C_NUM`（调查前两年出生的加权样本数）和 `FE_BORD_C_BO1` 至 `FE_BORD_C_BO5`（出生次序 1、2、3、4、5+ 的百分比）。这里的样本数不是国家出生总数，也不能用于决定不同国家的抽样权重。

- [指标定义 API](https://api.dhsprogram.com/rest/dhs/indicators?indicatorIds=FE_BORD_C_NUM,FE_BORD_C_BO1,FE_BORD_C_BO2,FE_BORD_C_BO3,FE_BORD_C_BO4,FE_BORD_C_BO5)
- [API 主站及使用文档](https://api.dhsprogram.com/)
- [DHS 统计指南第 8 版](https://www.dhsprogram.com/pubs/pdf/DHSG1/Guide_to_DHS_Statistics_DHS-8.pdf)
- [财富五分位定义](https://dhsprogram.com/Data/Guide-to-DHS-Statistics/Wealth_Quintiles.htm)
- [API 使用条款与署名要求](https://api.dhsprogram.com/html/terms.cfm)

每份调查保存其 ISO3、DHS 国家码、调查 ID、年份、来源 URL、指标 ID、`observed` 标签、加权出生数、财富/城乡/女性年龄组以及各组的出生次序分布。百分比保留 API 的一位小数，不伪造精度；抽样时对完整类别归一化。为避免使用不完整或无效表，某组如缺少出生次序值、分母非正或百分比和明显偏离 100，则不收录该组。

可复核例子：Kenya 2022 调查的总加权出生数 7101。最低、第二、中间、第四、最高财富五分位的出生数为 1593、1296、1284、1466、1462；归一化约为 22.43%、18.25%、18.08%、20.64%、20.59%。城乡出生数为 2562、4539，约 36.08%、63.92%。这些是出生样本的家庭背景分布，不能将五分位各占总人口 20% 推导为新生儿各占 20%。

## 口径与模型边界

1. **财富是国内相对资产地位。** DHS 的财富指数来自住房、资产、设施等，不能直接称为收入或全球购买力分位。调查时的家庭财富与城乡居住地也不一定等于出生当天的状态。
2. **女性年龄需保守处理。** 统计指南第 1.64 页说明一般背景年龄 `v012/v013` 是受访女性调查时年龄。本数据的普通 `Age (5-year groups)` 未获得足够字段级证据确认它在出生次序表中特别改成了分娩年龄，因此保守存储为 `age_at_survey_proxy_for_age_at_birth`。如将组中点减去参考窗口的一半来近似出生母龄，这是模型假设，不能标为逐岁出生年龄实测分布。母亲在调查时不满 15 岁、已满 50 岁或已经死亡等不在通常受访范围的情形也不是完整人口普查覆盖。
3. **出生次序不是现有手足数量。** 次序减一表示此前活产的数量下界/类别，不说明这些孩子是否仍存活或同住。`5+` 只能识别至少四次先前出生，不可声称恰好四个存活兄姐。指南第 1.66 页还说明双胞胎次序的特殊编码；该字段不能自动生成精确同胞家庭结构。
4. **条件表不是完整联合表。** 财富、居住地、年龄分别有出生次序条件分布；API 表没有同时按三者交叉的完整联合分布。若通过出生次序连接这些维度，必须标明“给定出生次序后条件独立”的合成假设。既有观测边际不能证明这一假设。
5. **年份和国家替代必须披露。** 最近一次或最近年份调查是时间代理，不能说是目标年份直接观测。未覆盖国家如果借用其他国家调查，则是跨国代理。跨国参考权重可以来自独立的国家出生总量，但不能用 DHS 样本量混合，也不能把一份参考调查当作全球代表。
6. **父亲年龄、父母职业、手足年龄不由本数据支持。** 同龄父母、固定间隔等都是透明的情景构造，不是官方人口频率。不得为了填满家庭字段而编造职业或年龄概率。
7. **不从总和生育率生成手足分布。** TFR 是一组年龄别生育率汇总的时期指标，不是已经出生的孩子数量分布，更不是一个新生儿的现有兄姐数。
8. **调查总体并非始终覆盖所有女性与地区。** `surveyUniverseWomen`、`surveyFootnotes`、实地调查起止时间均原样保留。例如部分调查仅访问曾婚女性，Pakistan 2017–18 的全国估计排除部分地区。`observed` 表示公开调查估计，不能解释成无遗漏的全国普查。
9. **参考窗口按下载时的指标定义记录为两年。** 各调查具体样本覆盖、历史重算与报告差异，应以对应调查及指标说明为准；本文件没有假定所有历次报告原始表都采用相同窗口。

## 许可与署名

官方 API 条款页面要求任何取得 API 数据的应用、网站、工具或文档提供指定署名；本包保留署名与来源。页面未声明 CC BY 许可，因此没有将 DHS 数据擅自标注为 CC BY 或公共领域。本包仅包含公开聚合指标，不包含需要申请的受限个体微观数据。

## 数据核验

已验证所有调查 ID 唯一、国家码为 ISO3、来源为官方 API、各收录组都有五个非负出生次序百分比且合计在 98–102 内。完整财富/城乡组的计数和与总出生数的差异通常在舍入范围；Malawi 2000 财富组相差 6、Turkmenistan 2000 相差 5，可能包含缺失背景类别或舍入，未人工强行改值。`categoryCountSums` 保留分组分母；抽样应使用相应组的实际计数和。年龄组存在缺省/零样本类别，不能把已收录类别当作所有年龄的完整普查。


## 本项目的抽样实现

运行时限定支持的地理项及完整财富五组、城乡、年龄组，实际使用 **298份调查、77国**。有本国调查时选择距出生年最近的一份；没有时，每个参考国家只保留距该年最近的一份调查，再用WDI基准年度出生权重选参考国。此跨国分布仅代表已覆盖DHS国家，不冒称本国或全球实测值。

在选中调查内，先按加权出生样本数抽财富组，再抽该组出生次序；母亲调查年龄组和城乡按给定出生次序的条件权重抽取。出生母龄用年龄组中点减两年回溯窗口的一半估算，父龄暂采用同龄代理。第5胎及以上只构造四位较年长手足的下界场景，不假定调查给出了他们的存活与同住情况。姓名、职业与手足年龄为叙事/模型生成。

未满18岁的父母统一使用「学习与家庭照料」作为叙事标签，避免出现未成年教师、医护人员等不合年龄的职业描述。18岁是本项目的叙事分界，不代表各国统一的就业或资格规定，也不是调查中的就业概率。此规则保留原职业抽签的随机数消耗，不改变家庭概率、父母年龄、姓名或成年父母的职业结果；旧存档不重写。

新存档记录来源调查、参考年份、是否跨国、财富概率、条件城乡概率与母亲年龄分布；旧存档不重新抽取家庭。出生登记中的「家庭抽签依据」展示这些信息。抽样验证包含30,000次确定种子试验、全完整调查可行性、概率归一化、跨国权重不受重复调查影响、年龄可行性和旧档兼容。
