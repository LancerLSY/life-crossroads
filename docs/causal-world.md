# 连续的世界与人物反应

一件事从哪里开始、实际做过什么、为什么停下来、最后怎样收尾，都保存到同一条线索中。世界线索保留最多3项正在进行的安排、6项已结束经历，每项最多8个过程节点；另外保存48条近期实际事实，供人物记忆与模型续写使用。

## 行动与时间

新的邀请是提议，付过一次学习费用也不代表作品已经完成。计划要通过不同年份的实际投入推进；选择跟进、或在之后的年份再次采取相关行动，都可能产生进展。完成需要能追溯到行动。仅过一年会提醒跟进，不会自动获得成功。

暂缓会保留到下一年，普通寒暄不能撤销已作出的决定。连续3次年度回顾都没有实际推进的安排会搁置，明确结束则记为主动放下，人物离世记为中断；这些都与完成分开显示。新消费不能为了腾出显示位置而替你结束旧计划，消费事实仍会留下。

健康较差时需要先照顾身体；事业重心与多名未成年孩子的照护可能挤占计划时间；同一年已实际推进另一项计划时，需要为下一项安排留出后续时间。这些限制影响共同计划的进度，普通消费、日常对话和关系修复仍可进行。

个人活动不会随意指定某个NPC为参与者。新故事只把已完成且人物、主题、地点相关的经历作为前因，不把无关的支持关系拼成引荐。相同人物的新邀请有间隔，婴幼儿NPC不会主动提出成人式共同计划。

## 关系也会变坏

对话仍由DeepSeek判断具体语义，本地规则处理关心、边界、敷衍、敌意和承诺。每年续写时，模型还会从NPC视角主动分析当前发生的事情，允许表达感激、被冷落、受伤及疏远。

年度判断必须引用当年、对应人物的事实。重复年度回顾没有跟进的计划，才可作为“被冷落”的依据；实际推进的记录才可支持“受到重视”。仅凭模型编出的指责不能扣分。既有伤害可以被重新提起，但不会因此再次处罚原来那一次行为。

目前“被冷落”一次结算亲密-2、信任-1；“受到重视”为亲密+1、信任+1，正向互动仍服从年度上限。每位NPC每年只结算一次主动评估，更换证据或重试请求都不会重复扣分，也不会用模型返回的任意数字改变关系。已有伤害会影响之后线索的方向，仍可以通过实际倾听、陪伴、帮助和兑现约定逐步修复。

## 当前生活也是事实

模型收到实际职业、教育、可用现金、债务、本年收支及未成年孩子数量。消费、迁居、选择、投资配置手续费与年度结算都会更新当前情境。同一个选择，无论立即点击后继续时间，还是由年度推进处理，都经过同一条结算路径，避免数值、费用或家庭事件出现两套结果。

旧存档保留原有人物和过去记录；后续推进使用新规则，缺少新字段也可载入。回溯与分支分别保存事实、计划经过和关系反馈。

这些仍是年度粒度的游戏规则。模型可以为当前一年创作新场景和人物表达，但本地规则决定哪些计划已经完成、支付了多少、以及关系究竟改变多少。
